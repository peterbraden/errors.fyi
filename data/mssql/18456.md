name: "Login Failed for User"
description: "Authentication to the SQL Server instance failed. The most common causes are an incorrect username or password, a disabled login, SQL Server Authentication not being enabled on the server, or a locked-out account. The accompanying state number in the SQL Server error log narrows down the exact cause."
