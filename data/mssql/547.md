---
name: "FOREIGN KEY or CHECK Constraint Conflict"
description: "An INSERT, UPDATE, or DELETE statement conflicted with a FOREIGN KEY or CHECK constraint. For inserts and updates, the referenced row does not exist; for deletes, dependent rows still reference the row being removed. The constraint name in the error message identifies which constraint was violated."
