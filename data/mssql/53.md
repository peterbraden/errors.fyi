---
name: "Named Pipes Provider - Could Not Open a Connection to SQL Server"
description: "The client could not reach the SQL Server instance over the network, often reported as 'Named Pipes Provider: Could not open a connection to SQL Server [53]'. Common causes are an incorrect server or instance name, the SQL Server Browser service not running for a named instance, a firewall blocking the port, or remote connections not being enabled on the server."
