---
name: "Cannot Insert Duplicate Key Row in Unique Index"
description: "An INSERT or UPDATE attempted to create a duplicate key value in a unique, non-primary-key index, and the statement was terminated. This is the unique-index counterpart of error 2627; the message identifies the index name and the duplicated key value."
