name: "unique constraint violated"
description: "An INSERT or UPDATE statement attempted to store a duplicate value in a column (or set of columns) with a UNIQUE or PRIMARY KEY constraint. Identify the constraint name in the error message, find the conflicting row, and either remove the duplicate or use MERGE/INSERT ... ON CONFLICT logic."
