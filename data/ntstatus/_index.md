---
title: "Windows NTSTATUS Codes"
description: "32-bit status and error codes returned by the Windows kernel, native API (ntdll.dll), and kernel-mode drivers. Distinct from Win32 error codes and HRESULTs, though both are commonly derived from an NTSTATUS value; the high bits encode severity, and the top two bits of a failure code are typically 0xC."
