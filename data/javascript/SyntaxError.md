---
name: "SyntaxError"
description: "Thrown when code being parsed does not conform to JavaScript's grammar, such as a mismatched bracket, invalid JSON passed to JSON.parse(), or an unexpected token. Unlike other native errors, a SyntaxError from a top-level script or module is raised at parse time, before any code runs."
references:
