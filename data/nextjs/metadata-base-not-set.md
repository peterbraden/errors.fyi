name: "Metadata Base Not Set"
description: "The metadataBase property is not set in the root layout's metadata export. metadataBase is required to resolve relative URLs in metadata fields such as openGraph.images and twitter.images. Without it, relative paths cannot be turned into absolute URLs for social sharing previews. Set metadataBase to your site's origin in the root app/layout.js file."
references:
