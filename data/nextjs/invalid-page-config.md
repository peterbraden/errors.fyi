name: "Invalid Page Config"
description: "A page file exports an invalid or unknown configuration option. In the Pages Router, only recognized exports such as getStaticProps, getServerSideProps, getStaticPaths, and config are permitted. In the App Router, valid segment config options include dynamic, revalidate, fetchCache, runtime, preferredRegion, and maxDuration. Check the export name for typos and consult the documentation for allowed values."
