name: "Plugin Error"
description: "A Nuxt plugin (a file in the plugins/ directory) threw an error during app initialisation. Plugins run before the root Vue component is mounted, so an unhandled error here prevents the entire app from starting. Wrap plugin code in a try/catch and use useError() to surface errors gracefully."
references:
